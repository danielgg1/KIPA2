NEW KNOWLEDGE RULES

1+ If the case does not include a file, 
    then conclusion: Juridical advisor should ask for more info

2+ If the required materials to take legal action are not all present, 
    then conclusion: the file is incomplete -> Juridical advisor should ask for more info.

3+ If the case is a complaint, and the employee has had earlier problematic behavior, 
    then conclusion: Juridical advisor should advise to go to court.

4+ If a complaint is about violence on the workplace, 
    then conclusion: Juridical advisor should advise to go to court.

5+ If the case is a complaint, but it is not about violence on the workplace, 
    then conclusion: Juridical advisor should start mediation process.

6+ If the warning is severe,
    then conclusion: Juridical advisor should advise to fire the employee.

7+ If the case is the third warning in a row, 
    then conclusion: Juridical advisor should advise salary suspension.

8+ If the case is a warning (but it is not severe and not third time in a row), 
    then conclusion: Juridical advisor should advise to send a warning letter.

9+ If the case is an improvement procedure, 
    then conclusion: Juridical advisor should advise to start mediation process.

10+ If the case is not an improvement procedure and also not complaint or warning, 
    then conclusion: The case is not suitable for labour law.
